# NOTHING BANTI — Fashion Storefront

A responsive fashion e-commerce demo built with plain HTML, CSS and JavaScript.

## Features
- Animated editorial hero, marquee, scroll reveals, hover motion
- Responsive product grid and category filters
- Sorting by price
- Interactive shopping bag with quantity controls and subtotal (session-only)
- Demo search and newsletter interaction
- Product images hosted by Unsplash
- Creator credit: **Banti AK1**

## Run locally
Open `index.html` in a browser. For best results use a local static server or GitHub Pages.

## Deploy to GitHub Pages
1. Create a public repository named `nothing-banti`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/(root)`, then **Save**.
6. Wait for GitHub Pages to finish deployment. Your URL will usually be `https://YOUR-USERNAME.github.io/nothing-banti/`.

## Important
This is a front-end concept/demo. Cart state is stored only in the current browser session. Checkout does not take payments, inventory is not managed, and newsletter emails are not saved. Connect a trusted commerce backend/payment provider before taking real orders. Replace demo images/prices and add real shipping, returns and contact details before launch.
